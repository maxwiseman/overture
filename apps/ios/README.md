# Overture — SwiftUI

Native iOS comparison build for the Overture editorial demo. It mirrors the Expo
prototype's home feed, article reader, explore search, saved stories, and alert
preferences using SwiftUI controls and navigation.

## Run

1. Open `Overture.xcodeproj` in Xcode.
2. Select the `Overture` scheme and an iPhone simulator running iOS 18 or newer.
3. Press Run.

The project has no third-party dependencies or package-install step.
